# Memoria Zero — demo

Visual novel investigativa ambientata nel 2071. Questa cartella è già giocabile: **non serve installare Ren'Py**. Il motore è incluso in `renpy-sdk`.

Scarica o clona **tutta** la cartella. I file di avvio devono restare accanto a `game` e `renpy-sdk`. Non spostarli da soli.

## Windows

Doppio clic su **`Avvia Memoria Zero.bat`**, nella cartella del progetto, accanto a `game` e `renpy-sdk`.

Non spostare quel file fuori dalla cartella: da solo non sa dove sta il gioco. Se lo vuoi sul Desktop, tasto destro sul bat, **Invia a**, **Desktop (crea collegamento)**. Il collegamento si può spostare. Il bat no.

## Mac

Doppio clic su **`Avvia Memoria Zero.command`**, nella cartella del progetto, accanto a `game` e `renpy-sdk`.

Non spostare quel file fuori dalla cartella: da solo non sa dove sta il gioco. Se lo vuoi sulla Scrivania, tasto destro sul file, **Crea alias**, e sposta solo l'alias. L'alias si può spostare. Il file no.

La prima volta macOS può bloccarlo perché il programma non è firmato. In quel caso: clic destro sul file, **Apri**, poi di nuovo **Apri**.

Se il doppio clic non fa nulla, apri il Terminale in questa cartella e lancia:

```bash
chmod +x "Avvia Memoria Zero.command"
./"Avvia Memoria Zero.command"
```

## Linux

Questa copia non include il motore Linux. Su Linux serve il [Ren'Py SDK](https://www.renpy.org/) 8.5: dal launcher scegli questa cartella e premi **Launch Project**.
