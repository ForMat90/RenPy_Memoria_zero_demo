# MEMORIA ZERO

# Image Generation Rules

## General Principles

Every generated asset must be:

- Production Ready
- RenPy Ready
- Correctly Cropped
- Organized
- Consistent

---

# Character Sprites

## Requirements

- PNG
- Transparent Background
- Properly Cropped
- No Embedded Background
- Full Body unless specified

---

## Resolution

Minimum:

2048px height

---

## Required Variations

Every character requires:

- Neutral
- Suspicious
- Shocked
- Angry
- Sad
- Distressed
- Broken

---

## File Naming

Examples:

Sarah_neutral.png

Sarah_angry.png

Sarah_shocked.png

Sarah_broken.png

---

# Backgrounds

## Resolution

1920x1080 minimum

Preferred:

3840x2160

---

## Requirements

No characters embedded.

Clean composition.

Suitable for dialogue overlays.

---

# Art Direction Consistency

Every prompt must follow:

- Retro-futurist minimalism
- White architecture
- Grey palette
- Crimson accents
- No cyberpunk neon

---

# Forbidden Elements

Avoid:

- Anime clichés
- Neon cyberpunk
- Fantasy aesthetics
- Medieval elements
- Cartoony styles

---

# Asset Goal

Every asset should feel like it belongs to Memoria Zero immediately.
